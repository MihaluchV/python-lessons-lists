# python-lessons
# Списки в Python — анімовані відео-уроки (9 клас)

У `index.html` зібрано чотири уроки, один урок для допитливих і практикум. На початковому екрані кнопками обирається будь-який з них, у довільній послідовності.

- **Урок 1. Основи списків** — опис нижче.
- **Урок 2. Продовження** — копіювання списку (`b = a` проти `copy()` і `a[:]`), об’єднання (`extend`, `+`), `count`, `min`, `max`, `sum`, створення списків (`[0] * 4`, `list(range(...))`, `list("рядок")`, `input().split()` і `list(map(int, ...))`, випадкові значення через `random.randint` та `random.sample`), задачі з циклом (відбір за умовою в новий список, зміна елементів на місці за індексом).
- **Урок 3. Алгоритми та генератори** — обмін елементів через `tmp` (з окремою тимчасовою кліткою), лінійний пошук, `sort(reverse=True)` і `sorted()`, типові помилки (`remove` видаляє лише перший збіг, `sort()` повертає `None`), генератори списків (`[a * 2 for a in ages]`, відбір з умовою `if`, зміна елементів за умовою `if ... else`, генератор з `range`); загальний вигляд запису показано у вікні перегляду, а частини запису підкреслюються в коді, коли диктор їх називає.
- **Урок 4. Типові задачі та рядки** — розворот списку вручну (два індекси `i` і `j`), видалення дублікатів (`not in`), циклічний зсув, рядки як послідовності (індекси, зрізи, незмінюваність), метод `join`, зворотний порядок слів у реченні (`split`, `reverse`, `join`).
- **⭐ Урок для допитливих** (без номера, необов’язковий) — сортування «бульбашкою», вибором, вставками, швидке сортування (quicksort), сортування злиттям і двійковий пошук. Стоїть після уроку 4, перед практикумом.
- **Урок 5. Практикум** — розбір п’яти задач: «Еко-патруль» (фільтрація й середнє), «Детектор спаму» (пошук за умовою), «Кіберспорт: Топ-3» (сортування, зріз, привітання), «Магічне перетворення» (заміна за умовою, цикл і генератор), «Знижка 20%» (ті самі ціни, але знижка застосовується прямо в основному списку за індексом, без нового списку). Для кожної задачі в правій частині екрана показано картку умови (контекст, вхідні дані, завдання, очікуваний результат), потім пауза «спробуйте самі», розв’язок крок за кроком з анімацією та перевірка.

У кінці уроку з’являється вибір: у першому уроці — завершити, повторити або перейти до наступного; в інших — ще й повернутися до попереднього (на останньому уроці кнопка «Наступний урок» неактивна, поки не з’явиться новий урок). «Завершити» повертає на початковий екран. Нові уроки додаються в кінець блоку `<script>` викликами `sc(...)` та записом `LS[n]={S,titles,starts}`.

Нижче — опис уроку 1.

Інтерактивний урок про одновимірні списки в Python з анімацією та озвучкою українською мовою. Це одна сторінка `index.html` без збирання й залежностей: її можна відкрити просто у браузері або опублікувати через GitHub Pages.

## Що в уроці

1. **Що таке список**: квадратні дужки, елементи, різні типи даних, порожній список, `print`.
2. **Індекси**: нумерація з нуля, від’ємні індекси, помилка `IndexError`.
3. **Зміна елемента** за індексом.
4. **Додавання**: `append`, `insert`.
5. **Видалення**: `remove`, `pop()`, `pop(i)` з переміщенням елемента в інше місце списку або в інший список, `del`.
6. **Корисне**: `len`, `in`, `index()` (разом із `ValueError`), `reverse()`, `sort()`.
7. **Зрізи**: `[a:b]`, `[:b]`, `[a:]`, зрізи з кроком `[a:b:k]`.
8. **Цикл `for`**: перебір елементів і перебір за індексами.
9. **Підсумок**.

Кортежі, словники й багатовимірні списки в уроці не розглядаються.

## Як це працює

- Кожен розділ відкривається кроком: спочатку диктор пояснює метод, а виділений рядок коду й сам метод мигають кольором. Потім іде розбір прикладу з анімацією: клітки з’являються, зсуваються, міняються місцями, тварини «переїжджають» між списками.
- У блоках «Додавання», «Видалення» й «Корисне» елементи списку — тварини в клітках, а позиції — самі клітки.
- Зліва вікно з кодом і консоль, справа список, стрілки-вказівники та рамки зі значеннями змінних.
- Керування: **Пуск / Пауза**, **Назад / Далі** (за розділами), вимкнення озвучки, кнопки розділів угорі.

## Як змінити зміст

Увесь урок описано в `index.html`, у блоці `<script>`. Розділи задаються викликами `sc('Назва розділу', [ ... ])`. Кожен крок — об’єкт:

| Поле | Призначення |
|------|-------------|
| `t`  | текст пояснення (він і озвучується, і показується як субтитр) |
| `t2` | необов’язковий коментар під час анімації прикладу |
| `a`  | функція з анімацією та діями над кодом і консоллю |
| `k`  | `1` — не прибирати стрілку й підсвічування перед поясненням |
| `p`  | необов’язкова функція, що виконується перед поясненням |

Тварини задаються в об’єкті `AN` (назва → емодзі). Приклади мають бути записані в `code([...])` та в `a` в одному порядку: номер рядка в `ln(n)` рахується від нуля.
